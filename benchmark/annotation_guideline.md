# 舆情风控 Benchmark 标注指南

当前 `cases.jsonl` 是由模板生成的候选集，`preannotation` 只是弱标注，不能直接当作论文或简历中的人工真值。人工审核后，将结果写入 `human_annotation`，并把 `annotation_status` 改为 `reviewed`。

## 标注原则

1. 只根据样本中的事件和文案判断，不补充外部事实。
2. 先判断文案是否真的造成风险，再判断风险类型和严重程度。
3. 关键词出现但上下文安全时，不标记为风险。
4. 一条文案可以有多个风险，全部记录。
5. 无法确定时标为 `uncertain`，不要强行二分类。

## 风险片段

`risk_spans` 记录触发风险的最小连续片段。`severity` 使用 1–5 分：

- 1：基本无风险或仅需润色；
- 2：轻微语气问题，可通过小幅修改解决；
- 3：可能引发明显负面舆情；
- 4：高概率造成信任损害或监管/安全风险；
- 5：涉及人身安全、隐私泄露、严重歧视或明确违法风险。

## 风险评分

法律、商业、声誉分别打 1–5 分。三项要独立判断，不要因为一个维度高就自动把另外两个维度也打高分。

## 推荐动作

只记录具体、可验证的动作，例如“公开核查范围和更新时间”“停止披露用户身份证号”“说明退款条件和完成时间”。“加强沟通”“持续关注”等空泛表述不能单独作为有效动作。

## 一致性

两名标注者先独立完成，不查看对方结果。冲突样本由第三人仲裁。报告中记录分类 Kappa、评分加权 Kappa 和风险片段 F1。
